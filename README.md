# VR-игра (учебный проект)

Проект на Unity с использованием XR Interaction Toolkit / OpenXR (VR-шлем).

## Требования

- **Unity `2022.3.34f1`** (точная версия важна — см. `ProjectSettings/ProjectVersion.txt`). Ставится через Unity Hub.
- **Git LFS** — обязательно, без него модели/текстуры/звуки не скачаются и будут "битыми".

## Установка

### 1. Поставить Git LFS (один раз на машину)

```bash
brew install git-lfs
git lfs install
```

Это нужно сделать **до** клонирования (или, если репозиторий уже склонирован без LFS — см. раздел «Если уже склонировали без LFS» ниже).

### 2. Склонировать репозиторий

```bash
git clone https://github.com/stasuik/My-game.git
```

Git LFS сам подтянет реальные бинарные файлы (`.fbx`, `.png`, `.wav`, `.blend` и т.д.) вместо текстовых заглушек-указателей.

### 3. Открыть проект в Unity Hub

Открыть папку репозитория как проект через Unity Hub, дождаться импорта пакетов (`Packages/manifest.json` — XR Interaction Toolkit, OpenXR, Universal RP и т.д. подтянутся автоматически).

### 4. Основные сцены

- `Assets/Scenes/SampleScene.unity` — стартовая сцена.
- `Assets/Scenes/Building Site.unity` — сцена стройки/основной геймплей.
- `Assets/Scenes/BasicScene.unity`, `New Scene.unity` — вспомогательные/тестовые.

## Если уже склонировали без LFS

Если модели в сцене выглядят битыми / отсутствуют, а файлы вроде `Assets/most.fbx` весят пару сотен байт и открываются как текст — это значит, что скачались LFS-указатели, а не сами файлы. Чинится так:

```bash
brew install git-lfs
git lfs install
git lfs pull
```

Проверить, что всё подтянулось:

```bash
git lfs fsck
```

Должно быть `Git LFS fsck OK` и никаких файлов-заглушек в рабочей копии.

## Известные особенности

- В `.gitattributes` настроен LFS для всех тяжёлых бинарных типов (модели, текстуры, аудио, видео, архивы и т.п.) — при добавлении новых файлов этих типов Git LFS подхватит их автоматически, ничего вручную настраивать не нужно.
- `Library/`, `Temp/`, `Obj/`, `Build*/`, `Logs/`, `UserSettings/` не хранятся в репозитории (см. `.gitignore`) — Unity пересоздаст их при первом открытии проекта, это нормально и может занять время.
