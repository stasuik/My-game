# Критерии приёмки задач — Спринт 1 «Кликабельная панель строительства»

Задача YouGile: ROA-23 (Ко). Формат: «как понять, что задача выполнена». Только проверяемое в шлеме / в сборке.
Статус критериев: **черновик на согласование** с Варей (аналитик) и тест-планом Паши (см. `04-alignment.md`).

## Разработка (Стас)

**ROA-39 Собрать кликабельную панель в игре**
- [ ] Нажатие кнопки на контроллере открывает панель перед игроком (~1.5 м, на уровне груди, лицом к игроку).
- [ ] Повторное нажатие закрывает панель.
- [ ] В панели видны варианты объектов (превью + название).
- [ ] Клик по варианту закрывает панель и в сцене появляется призрак/объект выбранного типа.
- [ ] После постановки на сцене виден поставленный объект.
- [ ] Поведение совпадает с описанием Степы (`06-panel-reactions.md`) без противоречий.

**ROA-38 Подключить заглушки дороги и туннеля**
- [ ] В превью панели видны заглушка дороги и заглушка туннеля.
- [ ] При выборе заглушки она ставится на сцену.

**ROA-37 Встроить UX-сценарии Степы в игру**
- [ ] Путь «открыть → выбрать → поставить», отмена и реакции работают так, как описано в UX-документе.
- [ ] Отдельного «поворота» из решений спринта нет; дороги поворачиваются интерактивно логикой.

## Заглушки и материалы (Диана)

**ROA-18 Заглушка дороги** — [ ] готов примитив сегмента (коробка/форма), [ ] передан Стасу.
**ROA-17 Заглушка туннеля** — [ ] готов примитив туннеля, [ ] передан Стасу.
**ROA-16 Варианты объектов для превью** — [ ] ≥2–3 простых варианта на категорию, [ ] визуально различаются в превью панели.
**ROA-15 Материалы под UI-кит** — [ ] 4 материала: асфальт, бетон, металл, дерево, [ ] согласованы с Соней.

## Тестирование (Паша)

**ROA-31 Читаемость панели в шлеме** — [ ] текст и кнопки читаются без прищуривания, [ ] замечания записаны и переданы Стасу и Соне.
**ROA-30 План тестирования** — [ ] план покрывает выбор и постройку, [ ] согласован с Варей.
**ROA-29 Тест-кейсы** — [ ] есть кейс на каждый сценарий выбора/постройки, [ ] отдельно крайние случаи (самый большой/маленький объект, край сцены).
**ROA-28 Smoke** — [ ] 10 сценариев, [ ] прогон ≈10 минут.
**ROA-27 Прогон сборки и отчёт** — [ ] отчёт по статусам задач, [ ] найденные баги записаны в доску.

## Документация (Степа, Варя)

**ROA-24 Реакция панели на действия** — [ ] описаны реакции на: открытие, выбор категории, выбор варианта, отмену.
**ROA-23 Критерии приёмки** — [ ] этот документ: у каждой задачи спринта есть проверяемый чек-лист.
**ROA-22 Сверка с заданием преподавателя** — [ ] таблица «пункт задания → наши задачи» (`03-teacher-assignment-matrix.md`).
**ROA-20 Документ спринта** — [ ] есть, [ ] доступен команде и преподавателю (`02-sprint-document.md`).
**ROA-19 Согласование с тест-планом** — [ ] расхождений между критериями и планом нет (`04-alignment.md`).
