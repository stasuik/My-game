# План тестирования — Спринт 1

Задача YouGile: ROA-30 (Паша). Черновик на согласование с Варей (критерии: `01-acceptance-criteria.md`).

## Цель
Проверить, что игрок может открыть панель, выбрать объект и построить его; панель читаема в шлеме.

## Объём
**Входит:** открытие/закрытие панели; содержимое и превью; выбор объекта; постановка одиночных объектов; построение дороги/моста по точкам; смена выбора; ограничения (дальность, близость дороги); читаемость в VR.
**Не входит:** отдельный поворот как фича панели (по решению спринта), настройки дороги, типы покрытия, авторасстановка, перекрёстки, производительность.

## Окружение
Unity 2022.3.34f1 · сцена `Building Site` · VR-шлем с OpenXR · для быстрой проверки логики допустим Play Mode с XR Device Simulator.

## Виды проверок
1. **Smoke** (`07-smoke.md`) — перед каждым показом, ≈10 мин.
2. **Функциональные** (`09-test-cases.md`) — по сценариям выбора и постройки.
3. **Крайние случаи** — самый большой/маленький объект, край сцены, пустой каталог, быстрые повторные нажатия.
4. **Юзабилити в шлеме** (ROA-31) — читаемость текста/кнопок, размер карточек, расстояние до панели.

## Критерии входа / выхода
- Вход: сборка запускается, есть доступ к шлему.
- Выход: все кейсы прогнаны, критичных (S1–S6) багов нет, найденные баги записаны в доску.

## Баги
Заводятся в доске YouGile: шаги, ожидание/факт, сборка (коммит), скрин/видео.
