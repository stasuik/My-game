# Спринт 1 — Кликабельная панель строительства

Задача YouGile: ROA-20. Проект: VR-песочница строительства дорог (Unity 2022.3.34f1, XR Interaction Toolkit / OpenXR).
Репозиторий: https://github.com/stasuik/My-game · Доска: YouGile → road builder game → «Спринт 1».

## Цель спринта
Внутриигровая кликабельная панель выбора объектов для постройки: игрок жмёт кнопку на контроллере, видит варианты, выбирает, и объект появляется на сцене (на заглушках, без финальных 3D-моделей). Панель читаема в шлеме.

## Что входит
- Открытие/закрытие панели кнопкой контроллера.
- Выбор варианта → призрак/объект на сцене.
- Заглушки дороги и туннеля, варианты для превью, 4 базовых материала.
- UX-описания, критерии приёмки, тест-план, кейсы, smoke, отчёт.

## Что НЕ делаем в этом спринте
- Отдельный «поворот» объекта как фича панели: по решению спринта дороги поворачиваются интерактивно самой логикой.
- Финальные 3D-модели (используем заглушки).
- Настройки дороги (тротуар/бордюр/столбы), типы покрытия в панели, авторасстановка придорожных объектов, перекрёстки (ТЗ §3.4–3.7) — следующие спринты.
- Расширенный перекрёсток при пересечении дорог (пост-MVP).

## Риски
- Тест «читаемость в шлеме» (ROA-31) требует физического шлема и участия Паши.
- Меню сейчас — плоский список без категорий; формулировка «категории» в ROA-39/ROA-24 требует решения (см. `05-code-gap-analysis.md`).
- Нет Unity-сборки в CI: проверка только вручную.

## Определение «готово»
Все задачи спринта проходят критерии из `01-acceptance-criteria.md`; smoke-набор (`07-smoke.md`) проходит за ≈10 минут без фатальных багов.
