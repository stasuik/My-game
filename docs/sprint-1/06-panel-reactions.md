# Реакция панели на действия игрока

Задача YouGile: ROA-24 (Степа). **Это описание текущего поведения по коду** (`VRMenuController`, `BuildManager`, `VRConstructionController`), а не UX-документ Степы. Его нужно сверить с авторским описанием Степы (ROA-37), расхождения вынести в `05-code-gap-analysis.md`.

| Действие игрока | Реакция системы | Источник |
|---|---|---|
| Нажатие кнопки меню на контроллере (action `toggleMenuAction`), панель закрыта | Панель появляется на расстоянии 1.5 м перед головой, ниже уровня глаз на 0.2 м, лицом к игроку. Первый раз кнопки строятся по каталогу, дальше переиспользуются | `VRMenuController.ToggleMenu`, `PositionMenuInFront` |
| Повторное нажатие той же кнопки, панель открыта | Панель закрывается, выбор не меняется | `ToggleMenu` |
| Выбор категории | **Не реализовано:** меню — плоская сетка карточек (3 колонки, при ≤2 объектах — по числу), прокрутка по вертикали | `BuildMenu` |
| Наведение на карточку | Подсветка карточки (ColorTint) | `CreateCard` |
| Клик по карточке варианта | Устанавливается текущий объект (`SetBuildMode(index)`), панель закрывается | `CreateCard`, `BuildManager.SetBuildMode` |
| Выбран обычный объект (не сплайн) | У луча руки появляется призрак объекта; поворот шагом 15° действиями rotateLeft/Right; триггер ставит объект | `UpdateSingleGhost`, `rotationStep` |
| Выбрана дорога/мост (сплайн) | Состояние Building: точки по триггеру, призрак пути; повтор | `VRConstructionController` |
| Цель дальше 50 м | Призрак красный, постановка невозможна | `maxBuildDistance`, `SetGhostColor` |
| Объект требует дорогу рядом, дороги нет | Постановка отклонена, предупреждение в лог (`Cannot place … too far from nearest road`); в шлеме для игрока ничего не видно | `requireRoadProximity` |
| Отмена | Смена выбранного объекта через панель сбрасывает текущую постройку и призрак. **Отдельной кнопки «Отмена» нет** | `CancelConstruction`, `ClearSingleGhost` |
| Пустой каталог | Панель открывается пустой, ошибки нет | `BuildMenu` |

## Открытые вопросы к Степе
1. Нужны ли категории (дороги / малые формы / …) или достаточно плоского списка?
2. Нужна ли явная отмена (кнопка/жест) и что она отменяет: выбор или текущую постройку?
3. Нужна ли обратная связь игроку при отказе постановки (текст/цвет/звук), сейчас только лог?
