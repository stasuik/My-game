# Согласование критериев приёмки с тест-планом

Задача YouGile: ROA-19 (Варя ↔ Паша). Сверка `01-acceptance-criteria.md` и `08-test-plan.md` / `09-test-cases.md`.

| Критерий | Проверка в тест-плане | Статус |
|---|---|---|
| Панель открывается по триггеру | S2, TC-01 | согласовано |
| Панель закрывается повторным нажатием | S3, TC-02 | согласовано |
| Видны варианты (превью + название) | S4, TC-03 | согласовано |
| Выбор → объект на сцене | S5–S6, TC-04, TC-05 | согласовано |
| Заглушки дороги/туннеля видны и ставятся | TC-03, TC-05 | **расхождение:** туннеля нет в проекте, проверять нечего, пока нет ROA-17 |
| Поведение совпадает с UX Степы | TC-06…08 | **расхождение:** UX-документ Степы не сверен, кейсы написаны по коду |
| «Категории» в панели | — | **расхождение:** категорий в коде нет, кейсов нет |
| Отмена | TC-07 | **расхождение:** явной отмены нет, проверяется только смена выбора |
| Читаемость в шлеме | S10, TC-12 | согласовано (нужен шлем) |
| Отчёт и баги в доске | план, ROA-27 | согласовано |

## Что решить, чтобы закрыть расхождения
1. Категории: делаем в спринте или убираем слово из критериев ROA-39/ROA-24.
2. Отмена: отдельное действие или смена выбора.
3. Туннель: ждём заглушку Дианы (ROA-17) или убираем из критериев ROA-38.
4. Получить UX-документ Степы и привести кейсы TC-06…08 к нему.
