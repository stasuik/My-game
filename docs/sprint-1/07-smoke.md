# Smoke-набор — 10 сценариев (~10 минут)

Задача YouGile: ROA-28 (Паша). Сборка: Unity 2022.3.34f1, сцена `Building Site`. Результат каждого: ✅ / ❌ + комментарий.

| № | Сценарий | Шаги | Ожидание |
|---|---|---|---|
| S1 | Запуск | Запустить сцену в шлеме | Сцена грузится, контроллеры видны, нет ошибок в консоли |
| S2 | Открыть панель | Нажать кнопку меню | Панель в ~1.5 м перед игроком, лицом к нему |
| S3 | Закрыть панель | Нажать кнопку ещё раз | Панель скрылась |
| S4 | Содержимое | Открыть панель | Видны карточки с превью и названием, нет пустых/битых |
| S5 | Выбор объекта | Кликнуть по любой карточке | Панель закрылась, у руки призрак объекта |
| S6 | Постановка | Навести на землю, нажать триггер | Объект появился на сцене |
| S7 | Дорога | Выбрать дорогу, 2–3 точки | Сегменты строятся, без разрывов |
| S8 | Смена выбора | Открыть панель, выбрать другой объект | Прежний призрак/постройка сбросились, новый выбран |
| S9 | Далеко | Навести дальше 50 м | Призрак красный, постановка не проходит |
| S10 | Читаемость | Прочитать названия кнопок на панели | Читаются без прищуривания |

Критерий: прогон ≈10 минут, фатальных багов (вылет, невозможность открыть панель/поставить объект) нет.
