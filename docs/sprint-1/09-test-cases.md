# Тест-кейсы — Спринт 1

Задача YouGile: ROA-29 (Паша). Статус прогона заполняется при тестировании.

| ID | Название | Предусловия | Шаги | Ожидаемый результат |
|---|---|---|---|---|
| TC-01 | Открыть панель | Сцена запущена | Нажать кнопку меню | Панель ~1.5 м перед игроком, лицом к нему |
| TC-02 | Закрыть панель | Панель открыта | Нажать кнопку меню | Панель скрыта |
| TC-03 | Содержимое панели | — | Открыть панель, пролистать | Все карточки с названием и превью, список прокручивается |
| TC-04 | Выбор объекта | Панель открыта | Кликнуть карточку | Панель закрыта, у руки призрак выбранного объекта |
| TC-05 | Постановка одиночного объекта | Выбран не-сплайн (фонарь/лавочка) | Навести на землю, триггер | Объект стоит на месте призрака |
| TC-06 | Постройка дороги | Выбрана «Дорога» | Поставить 3 точки | Сегменты без разрывов, призрак пути виден |
| TC-07 | Смена выбора в процессе постройки | Идёт постройка дороги | Открыть панель, выбрать другой объект | Прежняя постройка отменена, выбран новый |
| TC-08 | Повторный выбор | Объект уже выбран | Выбрать тот же | Нет ошибок, призрак на месте |
| TC-09 | Самый большой объект | В каталоге есть крупный (мост/грузовик) | Выбрать и поставить | Ставится, панель/сцена не ломаются |
| TC-10 | Самый маленький объект | Урна/знак | Выбрать и поставить | Ставится, превью читаемо |
| TC-11 | Край сцены / дальше 50 м | — | Навести за пределы | Призрак красный, постановка не проходит |
| TC-12 | Читаемость в шлеме | Шлем надет | Прочитать названия карточек с 1.5 м | Читается без прищуривания (замечания — Стасу и Соне) |
| TC-13 | Быстрые нажатия | — | Быстро открыть/закрыть панель 10 раз | Нет зависаний и дублей кнопок |
| TC-14 | Объект «рядом с дорогой» без дороги | Выбран объект с `requireRoadProximity` | Поставить далеко от дороги | Постановка отклонена (сейчас: только запись в лог) |
| TC-15 | Пустой каталог | Каталог пуст (редактор) | Открыть панель | Панель открывается, нет исключений |
| TC-16 | Поворот объекта (шаг 15°) | Выбран не-сплайн | rotateLeft/rotateRight | Призрак поворачивается на 15° (это не отдельная фича спринта, проверка регрессии) |

Покрытие: все сценарии выбора/постройки (TC-01…08), крайние случаи (TC-09…11, 13, 15), UX (TC-12, 14).
