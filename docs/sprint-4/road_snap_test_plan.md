# ROA-130 — тест-план привязки и стыковки

**Вход:** актуальная сборка с SnapPoint, сцена с дорогой/мостом, перечень поддерживаемых вариантов полосности, фактические параметры радиуса и угла, шаг дискретизации, решение по конфликтам стыковки. Сначала Play Mode с адресуемыми объектами и измерением мировых координат, затем ручной прогон в VR владельцем задачи.

| ID | Манипуляция и данные | Критерий |
|---|---|---|
| S01 | Дорога + дорога, одинаковая полосность, обе стороны каждого сегмента | Привязка к правильному концу; оси непрерывны; нет видимого зазора, ступеньки и наложения |
| S02 | Дорога + мост и мост + дорога, одинаковая полосность | Совпадение торцов и направления на входе/выходе, высота проезжей части непрерывна |
| S03 | Разная полосность для каждой пары типов, приоритет 1→3 и 3→1 | Для поддерживаемых пар — согласованный переходник и непрерывная ось. Для остальных — согласованная блокировка без изменения существующей трассы |
| S04 | Переключить ширину свободного и состыкованного сегмента; повторить переходом 1→3→1, если такая ширина доступна | Соответствует выбранной ширине; длина не меняется; при конфликте применяется согласованное правило, нет скрытой рассинхронизации соединений |
| S05 | Вытянуть по локальной Z, затем потянуть поперёк; длины 1,9 / 2 / 30 / 30,1 м | Границы и шаг соблюдены; боковое движение не искажает ширину и высоту |
| S06 | На границе радиуса; рядом две точки, ближайшая занята; проверить оба конца | Выбирается ближайшая допустимая точка, за пределами радиуса захвата нет; занятой точке не назначается второй стык |
| S07 | Обратное направление, угол чуть меньше/больше максимума, попытка самопересечения и замыкания кольца | Невалидные манёвры блокируются без повреждения сцены; допустимое кольцо, если оно предусмотрено, отличается от самопересечения |
| S08 | Повторно притянуть и оторвать сегмент; после фиксации сменить длину и ширину | Состояние привязки соответствует видимому результату; пустых ссылок и переключения на соседний стык без основания нет |
| S09 | Собрать кольцо и разветвлённый маршрут по 20+ сегментов | Стыки проверяются на щели и z-fighting; для ROA-127 замерить FPS и время кадра в шлеме, сравнить с целевым FPS сборки |
| S10 | Наводиться с 1, 3 и 5 м при двух темпах движения | Для ROA-128 записать долю успешных первых попыток, тестовый Snap Radius и замечания по дрожанию |

Считать покрытие по матрице утверждённого ТЗ. Для пар типов и полосности зафиксировать каждую поддерживаемую комбинацию, прогон и результат отдельно. Пороги численной погрешности, точное поведение несовместимых полос, занятой точки и самопересечения подтвердить со Стасом и Варей. Версия для согласования; фактический охват полного ТЗ подтверждается после сверки с ним.
