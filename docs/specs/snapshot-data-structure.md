# Спецификация структуры снимка состояния сцены (RoadActionSnapshot)

## 1. Контекст и архитектурный выбор
Для сохранения и восстановления игровых состояний дорожного редактора в VR используется гибридный подход: легковесные структуры дельта-снимков (`RoadActionSnapshot`), описывающие изменения конкретного элемента сцены, в сочетании с паттерном Command.

## 2. Структура данных снимка

### 2.1. Типы отменяемых действий (`ActionType`)
```csharp
namespace RoadBuilder.Core.History
{
    public enum ActionType : byte
    {
        CreateRoad = 0,
        DeleteRoad = 1,
        TransformRoad = 2,
        ModifyRoadProperties = 3,
        ConnectSnapPoints = 4,
        DisconnectSnapPoints = 5
    }
}
```

### 2.2. Модель снимка (`RoadActionSnapshot`)
Снимок фиксирует все критические параметры дорожного сегмента:
- `ObjectId`: Уникальный строковый или GUID-идентификатор сегмента на сцене.
- `PrefabId`: Имя или ID префаба дорожного сегмента (например, `"Road_2Lane_Straight"`).
- `Position`, `Rotation`, `Scale`: Мировые координаты и пространственная ориентация.
- `LaneCount`: Количество полос движения (1, 2, 3).
- `RoadType`: Тип дорожного полотна (Ground, Bridge, Tunnel).
- `Length`: Длина сегмента в метрах.
- `ConnectedNeighbors`: Список идентификаторов соседних присоединенных сегментов (для корректного восстановления топологии дорожной сети).
- `Timestamp`: Время совершения действия (Unix ms).

## 3. Бюджет памяти на элемент истории

| Поле | Тип данных | Размер (байт) | Описание |
| :--- | :--- | :--- | :--- |
| `ActionType` | `byte` | 1 | Тип операции |
| `ObjectId` | `string` (fixed/guid) | 36 | GUID строковый идентификатор |
| `PrefabId` | `string` (~16 chars) | 32 | ID префаба объекта |
| `Position` | `Vector3` (float x 3) | 12 | 3D-координаты |
| `Rotation` | `Quaternion` (float x 4) | 16 | Ориентация |
| `Scale` | `Vector3` (float x 3) | 12 | Масштаб |
| `LaneCount` | `int` | 4 | Количество полос |
| `RoadType` | `byte` | 1 | Тип дороги |
| `Length` | `float` | 4 | Длина секции |
| `ConnectedNeighbors` | `string[]` (до 4) | ~144 | Массив соседних ID |
| Накладные расходы объекта | C# Object Overhead | 32 | Ссылки и заголовок кучи |
| **ИТОГО на 1 запись** | | **~294 байт** | **Менее 0.3 КБ** |

При максимальном лимите стека в **50 действий** общее потребление памяти составляет **< 15 КБ**, что более чем в 100 раз меньше жесткого бюджета VR-проекта (2 МБ).
